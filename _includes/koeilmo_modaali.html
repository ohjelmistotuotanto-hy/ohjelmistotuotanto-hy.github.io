{% if lang == "en" %} Register for the course exam in Sisu by Sat 5.12.2026 at 23:59

The exam implementation is selected in your study plan in Sisu just like the course itself. Sisu has two different study plan views, and the implementation is selected slightly differently in each:

  • Old view: open the course brochure by clicking the course code and select the course exam implementation on the Completion methods tab
  • New view: the implementations are selected in the pop-up window that opens with the completion method

Once the implementation is selected, register for the exam on the Registration tab.
